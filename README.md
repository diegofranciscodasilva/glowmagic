## Glow Magic

Site institucional da Glow Magic, desenvolvido com HTML, CSS e JavaScript puro.

### Executar localmente

Abra o arquivo `index.html` no navegador ou inicie um servidor HTTP na raiz do projeto:

```powershell
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

### Estrutura

- `index.html`: estrutura e conteúdo da página.
- `assets/css/style.css`: estilos e responsividade.
- `assets/js/script.js`: menu, filtros, acordeões, navegação e lightbox.
- `assets/images/`: imagens do site.
